# Diamond-Price-Prediction
Diamond Price Prediction ML project that estimates diamond prices using features like carat, cut, color, and clarity. Performed EDA, preprocessing, and trained regression models to compare performance using R², MAE, and RMSE. Achieved accurate predictions demonstrating practical machine learning and data analysis skills.


💎 Diamond Price Prediction (Machine Learning Project)

This project builds a machine learning model to predict diamond prices based on their physical and quality attributes such as carat, cut, color, clarity, depth, table, and dimensions. The goal is to analyze how different features influence pricing and develop an accurate regression model for price estimation.

🚀 Key Features

Performed Exploratory Data Analysis (EDA) to understand feature relationships and detect outliers.

Applied data preprocessing techniques including encoding categorical variables and feature scaling.

Trained multiple regression models (Linear Regression, Decision Tree, Random Forest, etc.) to compare performance.

Evaluated models using metrics such as R² score, MAE, MSE, and RMSE.

Selected the best-performing model based on accuracy and generalization ability.

🛠 Tech Stack

Python

Pandas, NumPy

Matplotlib, Seaborn

Scikit-learn

📊 Outcome

The final model successfully predicts diamond prices with high accuracy and demonstrates how machine learning can assist in real-world pricing analysis.
